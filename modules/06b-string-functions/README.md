# Module 06b — String functions

## Mission

Customer and film data are full of text that must be cleaned, cut, and combined. Practise `CONCAT`, `UPPER`, `LOWER`, `LEFT`, `SUBSTRING`, `LEN`, `LTRIM`, and `RTRIM`. These tasks only read data.

## Exercise 1 — Add a prefix

Return `film_id` and the title with the prefix `Movie: `. Do not change the table.

## Exercise 2 — First 10 characters

Return `film_id`, the title, and its first 10 characters.

## Exercise 3 — Full name

Return `customer_id` and a `full_name` column built from first and last name. Use a string function.

## Exercise 4 — Case and length

For the first 20 customers by ID return the last name in upper case, the first name in lower case, and the length of the full name.

## Exercise 5 — Trim and cut

Show that `'   Sakila Video   '` is trimmed on both sides, and return characters 1–6 of the trimmed value.
