# Module 07 — Change data safely

## Mission

The operations team wants to add customers, correct data, and remove test records. Every change must be targeted, repeatable, and reversible.

## Exercise 1 — Insert a test film

Insert a film called `Extended Adventure` with a length of 150 minutes. Use the existing language ID for English and return the generated ID.

## Exercise 2 — Update one actor

Update actor ID 15 to `Robert`, but first show the row and make the update inside a transaction that can be rolled back.

## Exercise 3 — Delete only a course-created record

Delete the film `Extended Adventure` only if it was created by this exercise. Explain why deleting a film from Sakila can fail because of foreign keys.
