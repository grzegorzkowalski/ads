# Module 02 — Find the right records

## Mission

The marketing team wants targeted film lists. Your queries must handle operators, text patterns, missing values, and SQL Server data types correctly.

## Exercise 1 — Target categories

Return categories named `Animation`, `Family`, or `Children`.

## Exercise 2 — Find films in a duration range

Return films whose length is between 90 and 120 minutes, inclusive.

## Exercise 3 — Combine conditions

Return films whose title starts with `A`, whose release year is between 2005 and 2010, and whose rental duration is 4, 5, or 7 days.

## Exercise 4 — Find open rentals

Return rentals that have not been returned. Explain why `return_date IS NULL` is required.
