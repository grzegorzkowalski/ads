# Module 08c — Drop tables

## Mission

Remove tables safely, including tables that may not exist.

## Exercise 1 — Create and drop

Create `course_lab.employees` (`id int` primary key, `name varchar(50)`) and then drop it.

## Exercise 2 — Drop only if it exists

Drop `course_lab.temporary_table` only if it exists. Show two ways to do it.

## Exercise 3 — Dependencies

Create a table with a foreign key to another table and try to drop the referenced table first. What happens, and in what order must the tables be dropped?
