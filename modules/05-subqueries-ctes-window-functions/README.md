# Module 05 — Ask layered questions

## Mission

Managers rarely ask for one flat query. They ask for rankings, comparisons, and exceptions. Use subqueries, CTEs, and window functions to make those questions readable.

## Exercise 1 — Films above the average length

Return films whose length is greater than the average length of all films.

## Exercise 2 — Customers with at least one open rental

Return customers who currently have at least one rental with a `NULL` return date. Do not duplicate a customer who has several open rentals.

## Exercise 3 — Rank customers by revenue

Calculate each customer's total payment and rank them from highest to lowest.

## Exercise 4 — Top three films per category

Rank films within each category by rental rate and return only the first three per category.
