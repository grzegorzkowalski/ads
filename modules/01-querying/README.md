# Module 01 — Explore the catalogue

## Mission

You are onboarding as a data analyst. First, learn the shape of the Sakila catalogue before writing business reports.

## Exercise 1 — Select unique categories

Return every category name once, alphabetically.

## Exercise 2 — Inspect recent films

Return the title, release year, length, rental duration, rental rate, and rating for films released after 2005. Sort by release year and title.

## Exercise 3 — Inspect payment columns

Return the columns that describe a payment. Do not use `SELECT *`.

## Reflection

Why is an explicit column list safer than `SELECT *` in a report or view?
