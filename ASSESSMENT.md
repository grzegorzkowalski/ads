# Assessment guide

## Module work

Each module is practice-first. A student should be able to explain the query, not only execute it.

The course is complete only after Modules 01–16 and Project 3 have been submitted.

## Project rubric

| Area | Weight |
|---|---:|
| Correct SQL and expected results | 30% |
| Relational model and constraints | 20% |
| Transactions and error handling | 15% |
| Views, procedures, and functions | 15% |
| Indexes and execution-plan evidence | 10% |
| Documentation and presentation | 10% |

## Final capstone rubric

| Area | Weight |
|---|---:|
| Business requirements and data model | 20% |
| Correctness and test coverage | 25% |
| Transaction safety and error handling | 15% |
| Security and permissions | 10% |
| Performance evidence | 15% |
| Documentation and presentation | 15% |

## Minimum submission standard

- every SQL file can be run from a clean lab;
- no credentials are committed except the documented disposable image credentials;
- destructive operations are isolated or reversible;
- all junction tables have composite primary keys;
- the report states assumptions and limitations;
- the student includes screenshots or saved output for acceptance tests.
