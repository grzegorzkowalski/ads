# ADS 2026 completion checklist

## Environment

- [ ] Git installed
- [ ] Docker Desktop or approved remote SQL Server available
- [ ] Container starts and becomes healthy
- [ ] VS Code `mssql` or DataGrip connection works
- [ ] Environment verification script passes

## Core SQL

- [ ] Modules 01–07 completed
- [ ] Joins use the actual Sakila relationships
- [ ] `NULL` and empty-set cases are understood
- [ ] Data changes are tested in a transaction or disposable reset

## Database engineering

- [ ] Modules 08–12 completed
- [ ] Keys and constraints are justified
- [ ] At least one view, procedure, and function is created
- [ ] An execution plan comparison is documented
- [ ] A denormalized model is normalized to 3NF

## Advanced SQL Server

- [ ] Module 13 security exercise completed
- [ ] Module 14 concurrency exercise completed
- [ ] Module 15 JSON exercise completed
- [ ] Module 16 test and delivery exercise completed

## Final delivery

- [ ] Project 1 report completed
- [ ] Project 2 extension completed
- [ ] Project 3 capstone completed
- [ ] Acceptance tests pass from a clean lab
- [ ] README explains how another person can run the solution
- [ ] Presentation completed
